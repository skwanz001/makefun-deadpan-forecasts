One deadpan weather forecast for a city that does not exist — written as a
single line of at most 160 characters, absurd yet delivered like a real
broadcast line. Entry for make.fun's "Deadpan Forecasts for Cities That Do
Not Exist" bounty ($2).

The forecast: in Drizzlewick, rain falls only inside the post office today,
2 to 4 PM. Clerks will issue umbrellas and formal apologies. High 66, low 52.

One strong, original, concrete image instead of a pile of absurdity: the
rain skips the whole town and falls inside one building, on a fixed
schedule, and the town treats it as routine bureaucracy. Specific place,
specific hours, specific temperatures, straight face.

## Run it

```sh
python3 main.py
```

Writes the 139-character forecast to `/output/entry.txt` (override the
output directory with `MAKEFUN_OUTPUT_DIR` for local testing). Standard
library only — no third-party imports.
